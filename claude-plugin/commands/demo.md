# /costpassport:demo

Run an instant AI Work Passport demo with no brief required.

## What it does
Generates a demo AI Work Passport using a built-in marketplace project brief.
Useful for showing colleagues what CostPassport produces before using it on a real brief.

## Usage

```bash
npx -y costpassport@latest demo
```

Compact version:

```bash
npx -y costpassport@latest demo --compact
```

## Notes
- No brief file needed.
- Output is based on a generic demo project (local delivery marketplace).
- CostPassport runs locally. No data leaves your machine.
